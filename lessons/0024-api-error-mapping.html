把数据库结果翻译成稳定的 API 语义

Controller 不应直接泄露 DbErr。Service 先判断结果，再映射成客户端能理解的状态。

Service 代码与 SQL

let result = post::Entity::update_many()
    .col_expr(post::Column::Title, Expr::value(new_title))
    .filter(post::Column::TenantId.eq(tenant_id))
    .filter(post::Column::Id.eq(post_id))
    .exec(db)
    .await?;

if result.rows_affected == 0 {
    return Err(AppError::NotFound);
}
UPDATE "post"
SET "title" = $1
WHERE "tenant_id" = $2
  AND "id" = $3;

快速映射

  • 成功 → 204 No Content
  • 记录不存在 → 404 Not Found
  • 唯一约束或乐观锁冲突 → 409 Conflict
  • 未分类数据库错误 → 500 Internal Server Error
