从订单反查用户：belongs_to 与外键

第 6 课是用户查订单（一对多），本课反过来从订单查所属用户（多对一）。

1. 子实体声明 belongs_to

#[derive(Copy, Clone, Debug, EnumIter, DeriveRelation)]
pub enum Relation {
    #[sea_orm(
        belongs_to = "super::user::Entity",
        from = "Column::UserId",
        to = "super::user::Column::Id"
    )]
    User,
}

impl Related<super::user::Entity> for Entity {
    fn to() -> RelationDef { Relation::User.def() }
}

订单表保存 user_id，所以 order 是子实体，user 是父实体。belongs_to 描述外键方向。

2. 查询订单及所属用户

let rows = order::Entity::find()
    .find_also_related(user::Entity)
    .all(&db)
    .await?;

for (order, user) in rows {
    if let Some(user) = user {
        println!("order {} belongs to {}", order.id, user.email);
    }
}

find_also_related 返回订单和可选的用户。因为关联记录可能不存在，所以父实体是 Option<user::Model>。

3. 外键和删除策略

数据库外键保证 user_id 指向真实用户。删除用户时，RESTRICT、CASCADE、SET NULL 等策略会产生不同结果；策略必须和业务规则一致。

  2. find_also_related 中用户为什么是 Option？
