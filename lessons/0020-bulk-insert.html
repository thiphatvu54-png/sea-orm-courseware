用 insert_many 减少数据库往返

循环调用 insert 会产生多次往返；批量插入把多行写入合并成一次 SQL。

Rust 代码

let posts = vec![
    post::ActiveModel {
        title: Set("First".into()),
        status: Set("published".into()),
        ..Default::default()
    },
    post::ActiveModel {
        title: Set("Second".into()),
        status: Set("published".into()),
        ..Default::default()
    },
];

post::Entity::insert_many(posts)
    .exec(db)
    .await?;

对应 SQL

INSERT INTO "post" ("title", "status")
VALUES
    ('First', 'published'),
    ('Second', 'published');

真实 SQL 会根据数据库方言和 ActiveModel 字段变化；核心形状是一次 INSERT 携带多行。

快速判断

小批量可以直接一次提交；几万行时应按批次拆分，避免单条 SQL 过大、锁持有时间过长或超出参数限制。

练习：插入 1000 篇文章时，为什么通常优先用 insert_many，而不是循环调用 1000 次 insert？
