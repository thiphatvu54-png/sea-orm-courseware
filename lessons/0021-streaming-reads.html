不要把一百万行一次性放进内存

all(db).await? 会收集完整结果集；流式读取逐行消费，降低应用内存峰值。

Rust 代码

use futures_util::TryStreamExt;

let mut stream = post::Entity::find()
    .filter(post::Column::Status.eq("published"))
    .order_by_asc(post::Column::Id)
    .stream(db)
    .await?;

while let Some(post) = stream.try_next().await? {
    process(post);
}

对应 SQL

SELECT "post".*
FROM "post"
WHERE "status" = 'published'
ORDER BY "id" ASC;

这条 SQL 仍然返回所有匹配行，但应用侧逐行消费。流会占用连接直到结束或被丢弃；长时间处理时不要同时开启太多流。
