Lesson 0001 · 约 10 分钟

连接数据库，并理解 SeaORM 的四个核心类型

本课的目标是说清楚：数据库连接从哪里来，一张表在 Rust 中如何表示，以及读写数据分别使用什么类型。

1. 最小配置

[dependencies]
sea-orm = { version = "2.0.4", features = ["sqlx-sqlite", "runtime-tokio-rustls", "macros"] }
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }

2. 建立连接

use sea_orm::Database;

let db = Database::connect("sqlite::memory:").await?;

Database::connect 返回异步连接。URL 决定数据库类型；本课先用 SQLite，降低启动成本。

3. Entity、Model、ActiveModel、Column

  • Entity 是查询入口，例如 user::Entity::find()。
  • Model 是查询结果，代表数据库中的一行。
  • ActiveModel 用于插入或更新，字段可以单独设置。
  • Column 是列枚举，用于 filter、排序和选择。
回忆练习：如果要按 email 查询一名用户，你会从哪个类型开始？写出 Entity、Model、ActiveModel、Column 各自负责什么，再继续下一课。

4. 本课练习

  1. 写出 Database::connect("sqlite::memory:")。
  2. 解释为什么查询入口是 Entity，而不是 Model。
  3. 阅读官方文档中的连接数据库和 Entity 两节。
