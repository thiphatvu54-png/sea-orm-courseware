用复合游标避免重复与遗漏

只按 created_at 分页不够稳定：多条记录可能拥有相同时间戳。用唯一的 id 作为第二排序键，可以建立确定的顺序。

1. Rust 查询

let mut cursor = post::Entity::find()
    .order_by_desc(post::Column::CreatedAt)
    .order_by_desc(post::Column::Id)
    .cursor_by((post::Column::CreatedAt, post::Column::Id));

cursor.after((last_created_at, last_id));
let rows = cursor.first(20).all(db).await?;

2. 对应 SQL

PostgreSQL 风格的概念 SQL：

SELECT "post".*
FROM "post"
WHERE ("created_at", "id") < ($1, $2)
ORDER BY "created_at" DESC, "id" DESC
LIMIT 20;

跨数据库时，ORM 也可能展开成等价条件：

WHERE "created_at" < $1
   OR ("created_at" = $1 AND "id" < $2)

游标条件必须与 ORDER BY 方向一致；否则会跳过记录或重复返回记录。

练习：为什么只使用 created_at 作为游标，在同一时间戳有多条记录时会不稳定？id 在这里承担什么角色？
