批量写操作先写完整 WHERE

update_many 和 delete_many 没有过滤条件时可能影响整张表。多租户系统尤其不能漏掉 tenant_id。

批量更新

post::Entity::update_many()
    .col_expr(post::Column::Status, Expr::value("archived"))
    .filter(post::Column::TenantId.eq(tenant_id))
    .filter(post::Column::Status.eq("published"))
    .filter(post::Column::CreatedAt.lt(cutoff))
    .exec(db)
    .await?;
UPDATE "post"
SET "status" = 'archived'
WHERE "tenant_id" = $1
  AND "status" = 'published'
  AND "created_at" < $2;

批量删除

post::Entity::delete_many()
    .filter(post::Column::TenantId.eq(tenant_id))
    .filter(post::Column::Status.eq("draft"))
    .exec(db)
    .await?;
DELETE FROM "post"
WHERE "tenant_id" = $1
  AND "status" = 'draft';

生产操作前可先用相同 WHERE 做 SELECT COUNT(*) 预览，并检查返回的 rows_affected。
