避免并发请求互相覆盖

只按 id 更新会让后写入的请求覆盖先写入的修改。把读取到的 version 一起放进 WHERE，即可检测冲突。

Rust 代码

let result = post::Entity::update_many()
    .col_expr(post::Column::Title, Expr::value(new_title))
    .col_expr(
        post::Column::Version,
        Expr::col(post::Column::Version).add(1),
    )
    .filter(post::Column::Id.eq(post_id))
    .filter(post::Column::Version.eq(expected_version))
    .exec(db)
    .await?;

if result.rows_affected != 1 {
    return Err(Conflict);
}

对应 SQL

UPDATE "post"
SET "title" = $1,
    "version" = "version" + 1
WHERE "id" = $2
  AND "version" = $3;

rows_affected = 0 表示记录不存在，或版本已经被其他请求更新；此时应返回冲突，而不是强行覆盖。
