SeaORM 速查表

核心对象

  • Database::connect(url).await?：建立异步数据库连接
  • Entity：表的 Rust 类型入口
  • Model：一行记录的 Rust 数据
  • ActiveModel：用于插入和更新的可变模型
  • Column：列枚举，用于过滤、排序和选择

常见操作

use sea_orm::{EntityTrait, QueryFilter, ColumnTrait};
let user = user::Entity::find()
    .filter(user::Column::Email.eq("a@example.com"))
    .one(&db).await?;
记忆口诀：Entity 找数据，Model 读数据，ActiveModel 写数据，Column 描述条件。
